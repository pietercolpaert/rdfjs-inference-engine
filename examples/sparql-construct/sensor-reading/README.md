# Sensor readings

Select **Sensor readings** in either playground to load the same ontology,
provider SHACL, consumer SHACL and input data. The ontology maps a temperature
reading to an observation value and aligns its optional timestamp. The sample
contains a temperature of 18.4 and a timestamp.

The inference playground runs the bundled N3 rules. The SPARQL CONSTRUCT
playground translates the specialized rules and executes them with Comunica.
