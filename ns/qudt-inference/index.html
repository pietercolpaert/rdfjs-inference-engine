QUDT inference vocabulary

Configuration and result terms for normalizing QUDT quantity values and CDT/UCUM literals.

The HTML is also RDFa. Terms use the namespace https://www.pieter.pm/rdfjs-inference-engine/ns/qudt-inference#.

Configuration

UcumUnitIn
An RDF list of alternative QUDT units accepted from a CDT literal in SHACL IN shapes. It avoids multiple sh:unit values implying that one literal is simultaneously expressed in every listed unit.
normalizationProfile
Selects the normalization profile for an input property when dimension-only selection would be ambiguous or when an application wants a specific target quantity kind.
alignedQudtUnit
Relates a local unit identifier, code, or mapped vocabulary term to the corresponding QUDT unit used by the conversion rules.
targetLogarithmicUnit
Selects a logarithmic target unit for reversible linear-to-logarithmic conversion, for example turning a dimensionless ratio into decibels.
datatype
Current CDT datatype accepted by a normalization profile and used for quantity-specific normalized literals.
legacyDatatype
Legacy LINDT datatype accepted by a profile so older data can normalize to the same target representation as current CDT data.
targetUnit
Canonical QUDT unit emitted by a profile in qcr:normalizedQuantity objects.
targetUcumCode
Canonical UCUM code emitted by a profile in qcr:normalizedUcumLiteral and qcr:normalizedCdtLiteral lexical forms.
logBase
Base used by a logarithmic unit conversion, such as 10 for bel/decibel and 2 for octave.
logExponentMultiplier
Multiplier applied to the logarithmic source value before exponentiation, such as 0.1 for the documented decibel power-ratio convention.
logarithmicConvention
Semantic convention associated with a logarithmic unit, used to document whether the conversion represents a power ratio, field ratio, frequency ratio, or hydrogen-ion activity.

Results

normalizedQuantity
Links the input focus node to a generated qudt:QuantityValue in the target unit requested by the active normalization profile.
normalizedUcumLiteral
Provides the same normalized value as a compact cdt:ucum literal for applications that prefer literal values over QUDT quantity objects.
normalizedCdtLiteral
Provides the normalized value as a quantity-specific CDT literal when the profile has a known CDT datatype for that quantity kind.
normalizedLogarithmicQuantity
Links a linear input ratio to a generated logarithmic qudt:QuantityValue, such as a ratio converted to decibels.
normalizedLogarithmicUcumLiteral
Provides the logarithmic normalized value as a cdt:ucum literal using the configured logarithmic unit code.
sourceProperty
Records the input RDF property from which a normalized quantity or literal was derived.
sourceLiteral
Records the input CDT or UCUM literal from which a normalized result was derived.
sourceQuantity
Records the input QUDT QuantityValue object from which a normalized result was derived.
sourceUnit
Records the resolved QUDT source unit used for conversion, after UCUM code, symbol, local unit, or SKOS alignment resolution.

Profiles

  • AccelerationProfile normalizes acceleration values to metres per second squared.
  • AmountOfSubstanceProfile normalizes amount-of-substance values to moles.
  • AngleProfile normalizes plane angle values to radians.
  • AreaProfile normalizes area values to square metres.
  • CatalyticActivityProfile normalizes catalytic activity values to katal.
  • DimensionlessProfile normalizes ratios and other dimensionless values to QUDT unit:UNITLESS.
  • ElectricCapacitanceProfile normalizes electric capacitance values to farads.
  • ElectricChargeProfile normalizes electric charge values to coulombs.
  • ElectricConductanceProfile normalizes electric conductance values to siemens.
  • ElectricConductivityProfile normalizes electric conductivity values to siemens per metre.
  • ElectricCurrentProfile normalizes electric current values to amperes.
  • ElectricInductanceProfile normalizes electric inductance values to henries.
  • ElectricPotentialProfile normalizes electric potential values to volts.
  • ElectricResistanceProfile normalizes electric resistance values to ohms.
  • EnergyProfile normalizes energy values to joules.
  • ForceProfile normalizes force values to newtons.
  • FrequencyProfile normalizes frequency values to hertz.
  • IlluminanceProfile normalizes illuminance values to lux.
  • LengthProfile normalizes length values to metres.
  • LuminousFluxProfile normalizes luminous flux values to lumens.
  • LuminousIntensityProfile normalizes luminous intensity values to candela.
  • MagneticFluxProfile normalizes magnetic flux values to webers.
  • MagneticFluxDensityProfile normalizes magnetic flux density values to tesla.
  • MassProfile normalizes mass values to kilograms.
  • PowerProfile normalizes power values to watts.
  • PressureProfile normalizes pressure values to pascals.
  • RadiationDoseAbsorbedProfile normalizes absorbed radiation dose values to gray.
  • RadiationDoseEffectiveProfile normalizes effective radiation dose values to sieverts.
  • RadioactivityProfile normalizes radioactivity values to becquerels.
  • SolidAngleProfile normalizes solid angle values to steradians.
  • SpeedProfile normalizes speed values to metres per second.
  • TemperatureProfile normalizes absolute temperature values to kelvin using QUDT affine offsets.
  • TimeProfile normalizes duration and time-quantity values to seconds.
  • VolumeProfile normalizes volume values to cubic metres.

Logarithmic conventions

  • Power ratio convention used for bel and decibel conversions where the linear ratio is computed with a power-ratio exponent.
  • Field ratio convention used for neper conversions and documented separately from decibel power ratios.
  • Frequency ratio convention used for octave and decade conversions where the linear ratio represents a frequency ratio.
  • Hydrogen-ion activity convention used for pH conversion where the linear output represents hydrogen-ion activity.
