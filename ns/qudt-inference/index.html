QUDT inference vocabulary

Configuration and result terms for normalizing QUDT quantity values and CDT/UCUM literals.

The HTML is also RDFa. Terms use the namespace https://www.pieter.pm/rdfjs-inference-engine/ns/qudt-inference#.

Configuration

UcumUnitIn
An RDF list of alternative QUDT units accepted from a CDT literal.
normalizationProfile
Selects the normalization profile for an input property.
alignedQudtUnit
Relates a local unit identifier to the corresponding QUDT unit.
targetLogarithmicUnit
Selects a logarithmic target unit for a reversible linear-to-logarithmic conversion.
datatype
Current CDT datatype accepted by a profile.
legacyDatatype
Legacy LINDT datatype accepted by a profile.
targetUnit
Canonical QUDT unit emitted by a profile.
targetUcumCode
Canonical UCUM code emitted by a profile.
logBase
Base used by a logarithmic unit conversion.
logExponentMultiplier
Multiplier applied to the logarithmic exponent.
logarithmicConvention
Semantic convention associated with a logarithmic unit.

Results

normalizedQuantity
A normalized QUDT QuantityValue.
normalizedUcumLiteral
A normalized cdt:ucum literal.
normalizedCdtLiteral
A normalized quantity-specific CDT literal.
normalizedLogarithmicQuantity
A normalized logarithmic QUDT QuantityValue.
normalizedLogarithmicUcumLiteral
A normalized logarithmic cdt:ucum literal.
sourceProperty
Input RDF property from which a normalized result was derived.
sourceLiteral
Input CDT literal from which a normalized result was derived.
sourceQuantity
Input QUDT QuantityValue from which a normalized result was derived.
sourceUnit
Resolved QUDT source unit used for conversion.
