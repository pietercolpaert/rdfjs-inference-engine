RDF-JS inference inconsistency vocabulary

Machine-readable diagnostics emitted when an OWL 2 RL rule detects contradictory RDF.

The HTML is also RDFa. Terms use the namespace https://www.pieter.pm/rdfjs-inference-engine/ns/inconsistencies#.

Report terms

Inconsistency
A structured report that identifies a violated OWL 2 RL consistency condition.
rule
The OWL 2 RL diagnostic rule that produced the report.
term1
First ordered evidence term for a diagnostic rule.
term2
Second ordered evidence term for a diagnostic rule.
term3
Third ordered evidence term for a diagnostic rule.
term4
Fourth ordered evidence term for a diagnostic rule.
term5
Fifth ordered evidence term for a diagnostic rule.

Rules

The following identifiers are values of rule. Their local names follow the OWL 2 RL/RDF rules.

  • eq-diff1 reports that two resources are both owl:sameAs and owl:differentFrom.
  • eq-diff2 reports that members of an owl:AllDifferent list are inferred to be the same individual.
  • eq-diff3 reports that members of an owl:AllDifferent distinctMembers list are inferred to be the same individual.
  • prp-irp reports a reflexive use of a property declared owl:IrreflexiveProperty.
  • prp-asyp reports that an owl:AsymmetricProperty is used in both directions for the same pair of resources.
  • prp-pdw reports that two owl:propertyDisjointWith properties hold for the same subject and object.
  • prp-adp reports that two properties from an owl:AllDisjointProperties axiom hold for the same subject and object.
  • prp-npa1 reports that an owl:NegativePropertyAssertion for an object property is contradicted by a positive assertion.
  • prp-npa2 reports that an owl:NegativePropertyAssertion for a data property is contradicted by a positive assertion.
  • cls-nothing2 reports that a resource is typed as owl:Nothing.
  • cls-com reports that a resource belongs to a class and its owl:complementOf class.
  • cls-maxc1 reports a value for a property restricted by owl:maxCardinality 0.
  • cls-maxqc1 reports a qualified cardinality violation where maxQualifiedCardinality 0 excludes a value of the qualified class.
  • cls-maxqc2 reports a qualified cardinality violation where maxQualifiedCardinality 0 excludes an asserted value.
  • cls-maxqd1 reports a qualified data cardinality violation for maxQualifiedCardinality 0.
  • cax-dw reports that a resource is typed with two classes declared owl:disjointWith.
  • cax-adc reports that a resource is typed with two classes from an owl:AllDisjointClasses axiom.
  • dt-not-type reports a literal that does not satisfy the datatype constraints inferred for it.
