RDF-JS inference internal vocabulary

Implementation predicates used while evaluating bundled OWL, SHACL, and QUDT N3 profiles.

These terms are unstable implementation details and are normally filtered from application output. The HTML is also RDFa.

Terms

listRoot
Marks the root cell of an RDF list so list-oriented OWL rules can share one traversal result.
intersectionListRoot
Identifies the list that defines an owl:intersectionOf expression.
longIntersectionListRoot
Flags intersection lists that need iterative handling because they contain more than the compact direct case.
keyListRoot
Identifies the property list used by an owl:hasKey axiom.
propertyChainRoot
Identifies the list that defines an owl:propertyChainAxiom.
listPair
Stores adjacent list members as a pair for rules that compare or join consecutive values.
left
Left-hand value in an internal pair structure.
right
Right-hand value in an internal pair structure.
allListClassTypes
Memoized result saying that every class in a list types a candidate individual.
propertyChainHolds
Intermediate assertion that a property chain connects a subject to an object.
pathChain
Internal representation of a SHACL property path chain.
pathSubject
Subject node currently being evaluated for a SHACL path.
pathObject
Object node reached by evaluating a SHACL path.
sameValuesForProperties
Memoized comparison used by OWL key rules to determine whether two resources share all key values.
term
Generic slot for an RDF term carried through an internal diagnostic or validation structure.
canonicalLiteral
Canonical lexical representation used when comparing datatype literals.
complement
Internal link to the complement class used by OWL complement consistency checks.
literal
Literal value carried by an internal datatype validation result.
active
Marks an internal SHACL validation task that should be expanded by the rules.
focusFor
Associates a focus node with the shape currently being evaluated.
focus
Focus node of an internal SHACL validation result.
shape
Shape node responsible for an internal SHACL validation result.
path
SHACL path being evaluated by an internal validation rule.
pathValue
Value reached through a SHACL path before constraint checks are applied.
value
Value node that triggered or satisfied an internal validation step.
self
Marker used for SHACL self paths and self-referential path evaluations.
reifies
Connects an internal statement resource to the RDF triple it represents.
reifiesSubject
Subject component of an internally reified triple.
reifiesPredicate
Predicate component of an internally reified triple.
reifiesObject
Object component of an internally reified triple.
unitToken
Lexical unit token resolved from a QUDT symbol or UCUM code.
effectiveOffset
QUDT conversion offset after defaulting missing offsets to zero.
parsedQuantityLiteral
Parsed numeric value and source unit extracted from a CDT or UCUM literal.
convertedValue
Numeric result of a dimension-compatible QUDT conversion.
linearRatioFromLogValue
Linear ratio calculated from a logarithmic quantity using the configured convention.
logValueFromLinearRatio
Logarithmic value calculated from a positive linear ratio.
normalizationUnit
Canonical QUDT unit selected as a possible normalization source or target.
normalizationOutputProperty
Marks properties produced by normalization rules so they are not recursively normalized.
normalizedLexicalForm
Lexical form assembled for a normalized CDT or UCUM literal.
profileForDatatype
Maps a current or legacy CDT datatype to the normalization profile that handles it.
profileForGenericUcum
Selects a normalization profile for generic cdt:ucum input by matching QUDT dimensions.
profileForObjectProperty
Selects a normalization profile for QUDT quantity objects based on explicit property configuration or unit dimension.
